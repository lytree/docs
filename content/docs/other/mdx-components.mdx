## Accordion 手风琴

单个展开（默认），可加 `id` 生成锚点：

<Accordion>
  <AccordionItem title="什么是 Fumadocs？" id="what-is-fumadocs">
    一个基于 Next.js 的文档框架；本站是其 Vue 3 + TSX 复刻版。
  </AccordionItem>
  <AccordionItem title="支持多开吗？" id="accordion-multiple">
    设置 `type="multiple"` 后即可同时展开多项。
  </AccordionItem>
</Accordion>

多个同时展开（`type="multiple"`）：

<Accordion type="multiple">
  <AccordionItem title="默认展开项" defaultOpen>
    `defaultOpen` 让这一项初始即为展开状态。
  </AccordionItem>
  <AccordionItem title="另一项">
    multiple 模式下各项独立开合。
  </AccordionItem>
  <AccordionItem title="第三项">
    再来一条内容。
  </AccordionItem>
</Accordion>

## 代码块

带标题栏与行高亮（`{1}` 与 `[!code highlight]`）：

```ts title="example.ts" {1,3-5}
export function greet(name: string): string {
  const prefix = 'Hello'
  const message = `${prefix}, ${name}!`
  console.log(message)
  return message
}
```
