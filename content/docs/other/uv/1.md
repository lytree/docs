# uv 环境变量

`uv` 是由 Astral 推出的 Python 包与项目管理器(用 Rust 编写), 安装和解析依赖极快,
并能替代 `pip`、`virtualenv`、`pip-tools`、`pyenv` 等多个工具。

本文整理与 `uv` 相关的所有常用 **环境变量设置**、**安装**、**运行** 以及 **`.env` 示例**, 方便在 CI、本地开发、Docker 中复用。

---

## 1. 安装

### 1.1 macOS / Linux(官方一键脚本)

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

默认会安装到 `~/.cargo/bin/uv`(或 `~/.local/bin/uv`), 安装脚本会把目录写入 `PATH` 的提示输出。

### 1.2 macOS(Homebrew)

```bash
brew install uv
```

### 1.3 Windows(PowerShell)

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

或使用 `winget`:

```powershell
winget install --id=astral-sh.uv -e
```

### 1.4 指定版本安装

```bash
curl -LsSf https://astral.sh/uv/0.5.11/install.sh | sh
```

### 1.5 校验安装

```bash
uv --version
uv self update          # 升级 uv 自身
uv self update --revert # 回退到上一个版本
```

## 2. 常用环境变量

`uv` 的环境变量遵循 `UV_` 前缀的命名风格, 可在 Shell、`.env`、CI Secret、Docker `ENV` 中设置。

| 变量 | 作用 | 示例 |
| --- | --- | --- |
| `UV_INSTALL_DIR` | 指定 `uv` 二进制安装目录 | `UV_INSTALL_DIR=/opt/uv` |
| `UV_NO_CACHE` | 关闭全局缓存(等价于 `--no-cache`) | `UV_NO_CACHE=1` |
| `UV_CACHE_DIR` | 自定义缓存目录(默认 `~/.cache/uv`) | `UV_CACHE_DIR=/var/cache/uv` |
| `UV_LINK_MODE` | 安装包时链接策略(`copy` / `hardlink` / `symlink`) | `UV_LINK_MODE=copy` |
| `UV_SYSTEM_PYTHON` | 允许使用系统已有的 Python 解释器 | `UV_SYSTEM_PYTHON=1` |
| `UV_PYTHON` | 指定要使用或下载的 Python 版本 | `UV_PYTHON=3.12` |
| `UV_PYTHON_DOWNLOADS` | 是否允许自动下载 Python(`auto`/`always`/`never`) | `UV_PYTHON_DOWNLOADS=always` |
| `UV_PROJECT_ENVIRONMENT` | 自定义项目虚拟环境位置 | `UV_PROJECT_ENVIRONMENT=.venv` |
| `UV_VENV_CLEAR` | 重建 venv 前先清空 | `UV_VENV_CLEAR=1` |
| `UV_INDEX_URL` | 自定义 PyPI 镜像(也可走 `.env`) | `UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple` |
| `UV_EXTRA_INDEX_URL` | 额外的索引 URL(逗号分隔) | `UV_EXTRA_INDEX_URL=https://pypi.org/simple` |
| `UV_KEYRING_PROVIDER` | 凭据存储后端(`subprocess` / `import`) | `UV_KEYRING_PROVIDER=subprocess` |
| `UV_CONFIG_FILE` | 自定义配置文件路径(默认 `~/.config/uv/uv.toml`) | `UV_CONFIG_FILE=/etc/uv.toml` |
| `UV_NO_SYNC` | `uv run` 时跳过 `uv sync` | `UV_NO_SYNC=1` |
| `UV_OFFLINE` | 离线模式, 只使用本地缓存 | `UV_OFFLINE=1` |
| `UV_PRERELEASE` | 允许安装预发布版本 | `UV_PRERELEASE=allow` |
| `UV_LOCKED` | 锁文件严格模式(等价 `--locked`) | `UV_LOCKED=1` |
| `UV_FROZEN` | 不更新锁文件(等价 `--frozen`) | `UV_FROZEN=1` |
| `UV_LOG_LEVEL` | 日志级别(`trace`/`debug`/`info`/`warn`/`error`) | `UV_LOG_LEVEL=info` |
| `UV_HTTP_TIMEOUT` | 网络请求超时(秒) | `UV_HTTP_TIMEOUT=30` |
| `UV_CONCURRENT_DOWNLOADS` | 并发下载数 | `UV_CONCURRENT_DOWNLOADS=8` |
| `UV_COMPILE_BYTECODE` | 安装后编译 `.pyc` | `UV_COMPILE_BYTECODE=1` |
| `UV_BUILD_BACKEND` | 构建后端(`setuptools` / `hatchling` / `uv`) | `UV_BUILD_BACKEND=uv` |
| `UV_PUBLISH_URL` / `UV_PUBLISH_TOKEN` | 自定义发布仓库与令牌 | `UV_PUBLISH_URL=https://upload.pypi.org/legacy/` |
| `NO_COLOR` | 关闭 ANSI 颜色输出 | `NO_COLOR=1` |

> 提示: 完整的最新变量列表以 `uv help environment` 或官方文档为准。

## 3. 常用运行命令

### 3.1 项目初始化

```bash
uv init my-project          # 创建新项目(含 pyproject.toml)
uv init --package my-lib    # 创建可发布的库项目
uv init --bare              # 只生成 pyproject.toml, 不写示例代码
```

### 3.2 依赖安装

```bash
uv add requests                       # 添加运行时依赖
uv add --dev pytest ruff             # 开发依赖
uv add "fastapi>=0.110"               # 带版本约束
uv add "requests @ ./local-requests"  # 本地路径
uv add "git+https://github.com/.../"  # Git 仓库
uv remove requests                    # 移除
uv sync                               # 按锁文件完整同步
uv sync --frozen                      # CI 中常用, 不更新锁文件
uv lock --upgrade                     # 升级锁文件
uv pip install -r requirements.txt    # 兼容 pip 流程
```

### 3.3 虚拟环境

```bash
uv venv                            # 在当前目录创建 .venv
uv venv --python 3.12              # 指定 Python 版本
uv venv --seed                     # 附带安装 pip/setuptools
UV_PROJECT_ENVIRONMENT=/tmp/.venv uv venv
```

### 3.4 运行代码与工具

```bash
uv run python script.py            # 自动激活项目环境执行
uv run pytest                      # 在项目虚拟环境中跑测试
uv run --with rich python -c "from rich import print; print('hi')"
uv run --with requests -- python scrape.py
uv tool install ruff               # 全局工具(类似 pipx)
uv tool run black .                # 临时运行全局工具
uvx pycowsay hello                # uv tool run 的简写
```

### 3.5 Python 版本管理

```bash
uv python install 3.12
uv python list
uv python find 3.11
uv python pin 3.12                # 写入 .python-version
```

### 3.6 缓存与自检

```bash
uv cache info
uv cache clean
uv cache prune
uv self version
uv doctor                         # 环境健康检查
```

## 4. `.env` 示例

> `uv` 会自动从当前目录(及其父目录)的 `.env` 文件中读取环境变量。变量优先级:
> Shell 导出值 > `.env` > `pyproject.toml` 中 `[tool.uv]` 配置。

### 4.1 国内镜像加速 + 离线缓存

```dotenv
# .env
UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
UV_EXTRA_INDEX_URL=https://pypi.org/simple
UV_CACHE_DIR=/var/cache/uv
UV_LINK_MODE=copy
UV_HTTP_TIMEOUT=60
UV_CONCURRENT_DOWNLOADS=16
UV_COMPILE_BYTECODE=1
UV_LOG_LEVEL=info
```

### 4.2 固定 Python 版本(生产/CI)

```dotenv
# .env
UV_PYTHON=3.12.7
UV_PYTHON_DOWNLOADS=always
UV_PROJECT_ENVIRONMENT=/opt/app/.venv
UV_LOCKED=1
UV_FROZEN=1
UV_OFFLINE=0
NO_COLOR=1
```

### 4.3 CI(锁定依赖 + 关闭网络写入)

```dotenv
# .env
UV_FROZEN=1
UV_NO_CACHE=1
UV_OFFLINE=1
UV_LINK_MODE=copy
UV_LOG_LEVEL=warn
```

### 4.4 Docker 容器中常用配置

```dockerfile
FROM python:3.12-slim

# 安装 uv
COPY --from=ghcr.io/astral-sh/uv:latest /uv /uvx /usr/local/bin/

ENV UV_LINK_MODE=copy \
    UV_COMPILE_BYTECODE=1 \
    UV_PROJECT_ENVIRONMENT=/app/.venv \
    UV_PYTHON_DOWNLOADS=never \
    UV_CACHE_DIR=/root/.cache/uv

WORKDIR /app
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-dev
COPY . .
CMD ["uv", "run", "python", "main.py"]
```

### 4.5 私有仓库(企业内网)

```dotenv
# .env
UV_INDEX_URL=https://pypi.example.com/simple
UV_KEYRING_PROVIDER=subprocess
UV_EXTRA_INDEX_URL=
UV_PUBLISH_URL=https://pypi.example.com/legacy/
UV_PUBLISH_TOKEN=xxxxxxxxxxxxxxxxxxxx
```

### 4.6 `pyproject.toml` 中的等价配置

`.env` 只在运行时生效, 若希望把配置写进项目本身, 可在 `pyproject.toml` 中配置:

```toml
[tool.uv]
index-url = "https://pypi.tuna.tsinghua.edu.cn/simple"
extra-index-url = ["https://pypi.org/simple"]
link-mode = "copy"
compile-bytecode = true
cache-dir = "/var/cache/uv"

[tool.uv.pip]
no-cache = false
prerelease = "allow"

[[tool.uv.index]]
name = "internal"
url = "https://pypi.example.com/simple"
default = true
```

### 4.7 配置多个 `.env`(开发/生产)

```bash
# 开发
uv run --env-file .env.dev python app.py

# 生产
uv run --env-file .env.prod python app.py
```

## 5. 常见坑 & 排查

1. **`uv` 找不到 Python**: 设置 `UV_PYTHON=3.12` 或 `uv python install 3.12`。
2. **锁文件被改**: CI 中固定 `UV_FROZEN=1` / `uv sync --frozen`。
3. **私有仓库 401**: 设置 `UV_KEYRING_PROVIDER=subprocess`, 并确认 `~/.netrc` 或 keyring 中已有凭证。
4. **Docker 镜像缓存异常**: 设置 `UV_LINK_MODE=copy`, 避免硬链接/软链接跨层失效。
5. **想看真正生效的变量**: `uv run --no-sync python -c "import os;print(os.environ['UV_INDEX_URL'])"`。

## 6. 常用环境变量配置示例

以下示例按使用场景分组, 可直接复制到 `.env`、Shell `export`、CI `env:` 块或 Kubernetes/Docker Compose 中使用。

### 6.1 Shell 一次性临时设置

```bash
# 单次命令前临时注入
UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
UV_LINK_MODE=copy \
uv add fastapi
```

### 6.2 Shell 永久生效(Linux/macOS, 写入 `~/.bashrc` / `~/.zshrc`)

```bash
# uv 国内镜像 + 缓存策略
export UV_INDEX_URL="https://pypi.tuna.tsinghua.edu.cn/simple"
export UV_EXTRA_INDEX_URL="https://pypi.org/simple"
export UV_CACHE_DIR="$HOME/.cache/uv"
export UV_LINK_MODE="copy"
export UV_COMPILE_BYTECODE=1
export UV_PYTHON_DOWNLOADS="auto"
export UV_LOG_LEVEL="info"
export NO_COLOR=1
```

Windows PowerShell(写入 `$PROFILE`):

```powershell
$env:UV_INDEX_URL = "https://pypi.tuna.tsinghua.edu.cn/simple"
$env:UV_CACHE_DIR  = "$env:LOCALAPPDATA\uv\cache"
$env:UV_LINK_MODE  = "copy"
$env:UV_PYTHON     = "3.12"
```

### 6.3 GitHub Actions

```yaml
env:
  UV_INDEX_URL: https://pypi.tuna.tsinghua.edu.cn/simple
  UV_LINK_MODE: copy
  UV_COMPILE_BYTECODE: "1"
  UV_PYTHON: 3.12
  UV_PYTHON_DOWNLOADS: always
  UV_CACHE_DIR: /tmp/uv-cache

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: astral-sh/setup-uv@v3
        with:
          version: "0.5.11"
          enable-cache: true
          cache-dependency-glob: "uv.lock"
      - run: uv sync --frozen
      - run: uv run pytest
```

### 6.4 GitLab CI

```yaml
variables:
  UV_INDEX_URL: "https://pypi.tuna.tsinghua.edu.cn/simple"
  UV_LINK_MODE: "copy"
  UV_FROZEN: "1"
  UV_CACHE_DIR: "$CI_PROJECT_DIR/.cache/uv"

cache:
  key: uv-cache
  paths:
    - .cache/uv

uv-test:
  image: python:3.12-slim
  before_script:
    - curl -LsSf https://astral.sh/uv/install.sh | sh
  script:
    - uv sync --frozen
    - uv run pytest
```

### 6.5 Docker(单阶段/多阶段)

```dockerfile
# ---- builder ----
FROM python:3.12-slim AS builder

ENV UV_LINK_MODE=copy \
    UV_COMPILE_BYTECODE=1 \
    UV_PYTHON_DOWNLOADS=never \
    UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
    UV_PROJECT_ENVIRONMENT=/install

COPY --from=ghcr.io/astral-sh/uv:latest /uv /uvx /usr/local/bin/
WORKDIR /app
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-dev --no-install-project
COPY . .
RUN uv sync --frozen --no-dev

# ---- runtime ----
FROM python:3.12-slim
ENV PYTHONUNBUFFERED=1 \
    UV_LINK_MODE=copy \
    UV_NO_CACHE=1
COPY --from=builder /install /install
COPY --from=builder /app /app
WORKDIR /app
CMD ["uv", "run", "python", "main.py"]
```

### 6.6 Docker Compose

```yaml
services:
  api:
    image: my-api:latest
    environment:
      UV_INDEX_URL: https://pypi.tuna.tsinghua.edu.cn/simple
      UV_PYTHON: "3.12"
      UV_LINK_MODE: copy
      UV_FROZEN: "1"
      UV_NO_CACHE: "1"
      UV_LOG_LEVEL: info
      NO_COLOR: "1"
    volumes:
      - uv-cache:/root/.cache/uv

volumes:
  uv-cache:
```

### 6.7 Kubernetes(Deployment)

```yaml
env:
  - name: UV_INDEX_URL
    value: https://pypi.tuna.tsinghua.edu.cn/simple
  - name: UV_PYTHON
    value: "3.12"
  - name: UV_LINK_MODE
    value: copy
  - name: UV_FROZEN
    value: "1"
  - name: UV_NO_CACHE
    value: "1"
  - name: UV_PROJECT_ENVIRONMENT
    value: /app/.venv
envFrom:
  - secretRef:
      name: pypi-credentials   # 内部含 UV_PUBLISH_TOKEN / UV_KEYRING_PROVIDER
```

### 6.8 多镜像源(清华 + 阿里 + 官方)

```dotenv
# .env
UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
UV_EXTRA_INDEX_URL=https://mirrors.aliyun.com/pypi/simple,https://pypi.org/simple
```

### 6.9 离线 / Air-Gapped 环境

```dotenv
# .env
UV_OFFLINE=1
UV_NO_CACHE=0
UV_CACHE_DIR=/opt/uv-cache
UV_LINK_MODE=copy
UV_PYTHON_DOWNLOADS=never
UV_INDEX_URL=
UV_EXTRA_INDEX_URL=
```

### 6.10 调试 / 排错

```dotenv
# .env
UV_LOG_LEVEL=debug
UV_HTTP_TIMEOUT=120
UV_CONCURRENT_DOWNLOADS=1
UV_KEYRING_PROVIDER=subprocess
```

### 6.11 全局工具与 `uvx`

```dotenv
# 让 uv tool / uvx 也使用同样的镜像与缓存
UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
UV_CACHE_DIR=/var/cache/uv
UV_TOOL_BIN=/usr/local/bin
UV_TOOL_DIR=/var/lib/uv/tools
```

### 6.12 安全建议

- 不要把 `UV_PUBLISH_TOKEN` 等敏感值直接提交到仓库, 使用 CI Secret、K8s Secret、Vault 等托管。
- 多环境隔离使用 `--env-file .env.dev` / `.env.prod`, 配合 `gitignore` 排除真实 `.env`。
- CI 中固定 `UV_FROZEN=1` + `uv sync --frozen`, 保证依赖可复现。
- 容器里优先使用 `UV_LINK_MODE=copy`, 避免硬链接/软链接在镜像层之间失效。

## 7. 常用命令速查表

> 多数命令都支持 `-q` / `--quiet`、`-v` / `--verbose` 调整输出详细程度; 出错时先看 `uv doctor`。

### 7.1 安装与自身管理

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 查看版本 | `uv --version` | 输出版本号 |
| 查看 uv 信息 | `uv self version` / `uv self info` | 含安装路径、缓存目录 |
| 自升级 | `uv self update` | 升级 uv 自身 |
| 升级到指定版本 | `uv self update 0.5.11` | 升级到具体版本 |
| 回退版本 | `uv self update --revert` | 回退到上一版本 |
| 健康检查 | `uv doctor` | 检查 PATH、Python、网络 |
| 查看帮助 | `uv help` / `uv <cmd> --help` | 总览/单命令帮助 |
| Shell 补全 | `uv generate-shell-completion bash` | 生成补全脚本 |
| 卸载 uv | 官方安装脚本目录下执行 `uv self uninstall` | 一键卸载 |

### 7.2 项目初始化

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 创建应用项目 | `uv init my-project` | 生成 `pyproject.toml` 与示例 |
| 仅生成清单 | `uv init --bare` | 不创建示例代码 |
| 创建库项目 | `uv init --package my-lib` | 可发布的包结构 |
| 指定 Python | `uv init --python 3.12 my-app` | 锁定 Python 版本 |
| README 模板 | `uv init --readme` | 生成 README.md |
| 应用+库混合 | `uv init --app --package my-app` | 同时支持 |
| 已有项目导入 | `uv add requests` | 在已有项目里直接加依赖即可 |

### 7.3 依赖管理

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 添加依赖 | `uv add requests` | 写入 `pyproject.toml` 并安装 |
| 添加开发依赖 | `uv add --dev pytest ruff` | 进入 `[dependency-groups]` |
| 添加可选依赖 | `uv add --optional requests` | 进入 `[project.optional-dependencies]` |
| 移除依赖 | `uv remove requests` | 同时更新锁文件 |
| 带约束安装 | `uv add "fastapi>=0.110"` | 版本范围 |
| 限定版本 | `uv add "django==5.1.3"` | 精确版本 |
| 本地路径 | `uv add "pkg @ ./local-pkg"` | 路径依赖 |
| Git 依赖 | `uv add "git+https://github.com/x/y"` | 远程 Git 仓库 |
| 指定分支/标签 | `uv add "git+https://github.com/x/y@branch"` | Git ref |
| 同步环境 | `uv sync` | 按锁文件完整安装 |
| CI 同步 | `uv sync --frozen` | 不更新锁文件(推荐 CI) |
| 仅装 prod | `uv sync --no-dev` | 跳过开发依赖 |
| 包含可选组 | `uv sync --extra mysql` | 启用 `mysql` extra |
| 包含 group | `uv sync --group test` | 安装指定依赖组 |
| 升级锁文件 | `uv lock --upgrade` | 重新解析并更新 `uv.lock` |
| 升级单个包 | `uv lock --upgrade-package requests` | 仅升级指定包 |
| 锁检查 | `uv lock --check` | 检查锁文件与项目是否一致 |
| 导出 requirements | `uv export -o requirements.txt` | 生成 pip 兼容清单 |
| 导出(含 hash) | `uv export --no-hashes=false -o requirements.txt` | 适合安全审计 |
| 仅导出 prod | `uv export --no-dev -o requirements-prod.txt` | 排除开发依赖 |
| 解析依赖 | `uv tree` | 打印依赖树 |
| 反向依赖 | `uv tree --invert requests` | 谁依赖了 requests |

### 7.4 兼容 pip 命令(`uv pip`)

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 安装包 | `uv pip install requests` | 等价 `pip install` |
| 从 requirements | `uv pip install -r requirements.txt` | 读取 requirements.txt |
| 卸载包 | `uv pip uninstall requests` | 卸载 |
| 列出已装 | `uv pip list` | 列出环境内包 |
| 冻结 | `uv pip freeze` | 输出 `name==version` |
| 同步环境 | `uv pip sync requirements.txt` | 与 requirements 完全一致 |
| 检查一致性 | `uv pip check` | 检查依赖冲突 |
| 显示包信息 | `uv pip show requests` | 元数据 |
| 编译 | `uv pip compile pyproject.toml -o requirements.txt` | 类似 pip-compile |

### 7.5 虚拟环境

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 创建虚拟环境 | `uv venv` | 在当前目录创建 `.venv` |
| 指定 Python | `uv venv --python 3.12` | 选择解释器版本 |
| 自定义名称 | `uv venv .venv-3.12 --python 3.12` | 自定义路径 |
| 附带 pip | `uv venv --seed` | 一起装 pip/setuptools |
| 升级种子包 | `uv venv --seed --upgrade` | 升级种子包 |
| 清空重建 | `uv venv --clear` | 重建前清空 |
| Relocatable | `uv venv --relocatable` | 生成可重定位 venv |
| 指定提示符 | `uv venv --prompt myenv` | shell 提示符前缀 |
| 指定链接策略 | `uv venv --link-mode copy` | 容器场景 |

### 7.6 运行命令(`uv run`)

| 场景 | 命令 | 说明 |
| --- | --- | --- |

## 8. Windows 永久环境变量设置

Windows 上有 4 种常见做法: **PowerShell `$PROFILE`**(当前用户)、**系统属性 / `setx`**(用户级/系统级)、**注册表**、以及 **批处理脚本**。选其一即可, 不要重复设置同一个变量。

> 说明:PowerShell 改完 `$PROFILE` 之后, **新打开的 PowerShell 窗口**才会加载(已有的窗口要 `. $PROFILE` 重新加载)。`setx` 修改的是**用户级**环境变量,需要重新打开终端才生效。

### 8.1 方式一:PowerShell `$PROFILE`(推荐, 当前用户)

打开 PowerShell, 先确认 `$PROFILE` 文件位置:

```powershell
echo $PROFILE
# 通常是: C:\Users\<你>\Documents\PowerShell\Microsoft.PowerShell_profile.ps1
```

如果目录不存在, 先创建:

```powershell
# 为当前用户创建 PowerShell 配置目录与文件
New-Item -Path (Split-Path $PROFILE) -ItemType Directory -Force
New-Item -Path $PROFILE -ItemType File -Force
```

在 `$PROFILE` 末尾追加以下内容(用记事本或 IDE 直接编辑也可):

```powershell
# ---- uv 环境变量 ----
$env:UV_INDEX_URL        = "https://pypi.tuna.tsinghua.edu.cn/simple"
$env:UV_EXTRA_INDEX_URL  = "https://pypi.org/simple"
$env:UV_CACHE_DIR        = "$env:LOCALAPPDATA\uv\cache"
$env:UV_LINK_MODE        = "copy"
$env:UV_COMPILE_BYTECODE = "1"
$env:UV_PYTHON           = "3.12"
$env:UV_PYTHON_DOWNLOADS = "auto"
$env:UV_LOG_LEVEL        = "info"
$env:NO_COLOR            = "1"

# 把 uv 安装路径加入 PATH(若使用官方安装脚本默认目录)
if (Test-Path "$env:LOCALAPPDATA\uv") {
    $env:Path = "$env:LOCALAPPDATA\uv;$env:PATH"
}
```

立即生效:

```powershell
. $PROFILE   # 在当前窗口重新加载
uv --version
```

> 若使用 **PowerShell 7 (pwsh)**, `$PROFILE` 路径是 `~\Documents\PowerShell\Microsoft.PowerShell_profile.ps1`; 若使用 **Windows PowerShell 5.1**, 则是 `~\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`, 二者**互不通用**, 需要分别配置。

### 8.2 方式二:`setx`(用户级永久, 无需管理员)

```powershell
# 用户级(影响当前 Windows 账户下所有进程)
setx UV_INDEX_URL        "https://pypi.tuna.tsinghua.edu.cn/simple"
setx UV_EXTRA_INDEX_URL  "https://pypi.org/simple"
setx UV_CACHE_DIR        "%LOCALAPPDATA%\uv\cache"
setx UV_LINK_MODE        "copy"
setx UV_COMPILE_BYTECODE "1"
setx UV_PYTHON           "3.12"
setx UV_PYTHON_DOWNLOADS "auto"
setx UV_LOG_LEVEL        "info"
setx NO_COLOR            "1"

# 把 uv 加入 PATH(用户级)
setx PATH "%LOCALAPPDATA%\uv;%PATH%"
```

> 注意:
> - `setx` 的值长度上限约 **1024 字符**, 拼接过长的 `PATH` 不适合用 `setx`。
> - `setx` **不会立刻修改当前终端**的环境变量, 需**重新打开** PowerShell / CMD。
> - 想清空某个变量: `setx UV_INDEX_URL ""`。

### 8.3 方式三:系统属性 GUI(适合不喜欢命令行的同学)

1. `Win + R` → 输入 `sysdm.cpl` → 回车。
2. 切到 **高级** 选项卡 → 点击 **环境变量(N)…**。
3. 在 **用户变量(U)**(只影响当前账户)或 **系统变量(S)**(影响所有账户, 需要管理员)中:
   - 点 **新建(W)…**, 变量名填 `UV_INDEX_URL`, 变量值填 `https://pypi.tuna.tsinghua.edu.cn/simple`。
   - 重复操作, 把其余 `UV_*` 变量依次加入。
4. 要把 uv 加到 `Path`, 在 **用户变量** 中选中 `Path` → **编辑(I)…** → **新建(N)** → 输入 `%LOCALAPPDATA%\uv`(或 uv 实际安装目录, 如 `C:\Program Files\uv`)。
5. 一路 **确定** 保存。**重新打开终端**后生效。

### 8.4 方式四:直接编辑注册表(系统级 / 自动化脚本)

> 不熟悉注册表请跳过本节; 改错可能影响系统。

```powershell
# 把变量写入 当前用户 环境
$vars = @{
    "UV_INDEX_URL"        = "https://pypi.tuna.tsinghua.edu.cn/simple"
    "UV_EXTRA_INDEX_URL"  = "https://pypi.org/simple"
    "UV_CACHE_DIR"        = "$env:LOCALAPPDATA\uv\cache"
    "UV_LINK_MODE"        = "copy"
    "UV_COMPILE_BYTECODE" = "1"
    "UV_PYTHON"           = "3.12"
}

$reg = "HKCU:\Environment"
foreach ($k in $vars.Keys) {
    Set-ItemProperty -Path $reg -Name $k -Value $vars[$k]
}

# 让系统立刻广播环境变量变更(向所有运行中的进程发出 WM_SETTINGCHANGE)
Add-Type -Namespace Win32 -Name Broadcast -MemberDefinition @"
[System.Runtime.InteropServices.DllImport("user32.dll", CharSet=System.Runtime.InteropServices.CharSet.Auto)]
public static extern int SendMessageTimeout(IntPtr hWnd, uint Msg, IntPtr wParam, IntPtr lParam, uint flags, uint timeout, out IntPtr result);
"@
[Win32.Broadcast]::SendMessageTimeout([IntPtr]0xFFFF, 0x001A, [IntPtr]0, "Environment", 2, 5000, [ref][IntPtr]::Zero) | Out-Null
```

或者通过 `.reg` 文件一次性导入:

### 8.5 方式五:项目级 `.env`(仅当前项目)

如果不想改全局, 只想在某个项目里生效, 在项目根目录创建 `.env`:

```dotenv
UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
UV_LINK_MODE=copy
UV_PYTHON=3.12
UV_COMPILE_BYTECODE=1

```

`uv run` 会自动读取它(优先级最高, 仅作用于当前项目)。记得把 `.env` 加入 `.gitignore`, 或者使用 `.env.example` 提交模板。

### 8.6 验证设置是否生效

```powershell
# 在新打开的 PowerShell 中
uv run --no-sync python -c "import os,uv_helper; print(os.environ.get('UV_INDEX_URL'))"
# 或者直接看 uv 自己的输出
uv config --no-header
uv pip install --dry-run requests
```

如果输出符合预期, 说明 `uv` 已经读取到你的环境变量; 否则检查:
- 终端是否是新打开的(老终端不会自动刷新环境变量)。
- 变量名是否拼写正确(必须以 `UV_` 开头, 大小写敏感)。
- 是否把变量写到了 **系统变量**, 但读取时用了 **用户变量**(优先级:系统 > 用户)。

### 8.8 PowerShell (`pwsh`) 专属配置

> 这一节针对跨平台 **PowerShell 7 (`pwsh`)**——Windows / macOS / Linux 通用, 推荐作为日常开发 Shell。如果只用 Windows 自带的 **Windows PowerShell 5.1**, 可跳过 8.8.2、8.8.5 这些针对 pwsh 的小节。

#### 8.8.1 安装 pwsh

```powershell
# Windows(winget)
winget install --id Microsoft.PowerShell -e

# macOS(Homebrew)
brew install --cask powershell

# Linux(microsoft 官方 apt 源)
# 见: https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-linux
```

验证:

```powershell
$PSVersionTable.PSVersion   # 应 >= 7.4
$IsWindows / $IsLinux / $IsMacOS
```

#### 8.8.2 pwsh 与 Windows PowerShell 5.1 的差异(对 uv 配置的影响)

| 项目 | Windows PowerShell 5.1 | PowerShell 7 (`pwsh`) |
| --- | --- | --- |
| 可执行文件 | `powershell.exe` | `pwsh.exe` |
| `$PROFILE` 路径 | `~\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1` | `~\Documents\PowerShell\Microsoft.PowerShell_profile.ps1` |
| 默认 Shell | Windows 系统自带 | 需手动安装 |
| 跨平台 | ❌ 仅 Windows | ✅ Win/macOS/Linux |
| 模块兼容性 | 多数老旧模块 | 大部分兼容,部分老模块需要 WinPS5.1 |
| PSReadLine | 内置 | 推荐另装 `PSReadLine` 2.x |

**关键点:两者的 `$PROFILE` 互不通用**, 你在 pwsh 里设置的 `UV_*` 不会影响 5.1。需要分别配置或只配置其中之一。

#### 8.8.3 pwsh `$PROFILE` 路径与初始化脚本

```powershell
# 查看当前 pwsh 的所有 profile 路径

```

典型输出(按加载顺序):

```

AllUsersCurrentHost    : C:\Program Files\PowerShell\7\Microsoft.PowerShell_profile.ps1
CurrentUserAllHosts    : C:\Users\<你>\Documents\PowerShell\profile.ps1
CurrentUserCurrentHost : C:\Users\<你>\Documents\PowerShell\Microsoft.PowerShell_profile.ps1

> 修改 `CurrentUserCurrentHost` 最常见, 也是大多数教程所说的 `$PROFILE`。

一键创建/编辑:

```

#### 8.8.4 推荐 pwsh `$PROFILE` 模板(含 uv / Python / 提示符)

```powershell
# ============================================================
# pwsh profile - 通用开发环境配置
# ============================================================

# ---- 错误时不中断交互式 shell ----
$ErrorActionPreference = 'Continue'

# ---- 常用别名 ----
Set-Alias -Name ll    -Value Get-ChildItem
Set-Alias -Name g     -Value git
Set-Alias -Name py    -Value python
Set-Alias -Name grep  -Value Select-String

# ---- 1. uv 专用环境变量(只对当前 pwsh 进程生效) ----
$env:UV_INDEX_URL        = "https://pypi.tuna.tsinghua.edu.cn/simple"
$env:UV_EXTRA_INDEX_URL  = "https://pypi.org/simple"
$env:UV_CACHE_DIR        = if ($IsWindows) { "$env:LOCALAPPDATA\uv\cache" } else { "$HOME/.cache/uv" }
$env:UV_LINK_MODE        = "copy"
$env:UV_COMPILE_BYTECODE = "1"
$env:UV_PYTHON           = "3.12"
$env:UV_PYTHON_DOWNLOADS = "auto"
$env:UV_LOG_LEVEL        = "info"
$env:NO_COLOR            = "1"

# ---- 2. uv 可执行文件加入 PATH(官方安装脚本默认目录) ----
$uvBin = if ($IsWindows) { "$env:LOCALAPPDATA\uv" } else { "$HOME/.local/bin" }
if (Test-Path $uvBin) {
    if ($env:Path -notlike "*$uvBin*") {
        $env:Path = "$uvBin;$env:Path"
    }
}

# ---- 3. uv shell 补全(pwsh 原生支持) ----
uv generate-shell-completion pwsh | Out-String | Invoke-Expression

# ---- 4. 提示符:显示当前目录的 Python/uv 环境 ----
function Get-PyPrompt {
    $py = ""
    if ($env:VIRTUAL_ENV) {
        $py = " ($((Split-Path $env:VIRTUAL_ENV -Leaf)))"
    } elseif (Test-Path .python-version) {
        $py = " ($(Get-Content .python-version -ErrorAction SilentlyContinue))"
    }
    "$PWD$py> "
}

# 只有在交互式 shell 才覆盖 prompt, 避免脚本里出问题
if ([Environment]::UserInteractive -and $Host.Name -eq 'ConsoleHost') {
    function prompt { Get-PyPrompt }
}
```

> 加载:`. $PROFILE`,或在当前 shell 输入 `reload`(`Set-Alias reload '. $PROFILE'` 之后)。

#### 8.8.5 pwsh 专属命令(扩展 uv 体验)

```powershell
# 列出 pwsh 进程里所有 UV_* 变量
Get-ChildItem Env:UV_*

# 一键显示 uv 当前生效的索引、缓存、Python
uv config --no-header | Format-List

# 用 pwsh 的 where-Object 过滤 uv 输出
uv tree --depth 2 | Select-String "fastapi"

# 函数:在当前目录一键 uv sync 并跑测试
function Invoke-UvTest {
    uv sync --frozen
    uv run pytest @args
}
Set-Alias -Name uvt -Value Invoke-UvTest

# 函数:进入项目并自动激活 .venv
function Enter-UvProject($Path) {
    Set-Location $Path
    if (Test-Path .venv) {
        & .\.venv\Scripts\Activate.ps1   # Windows
        # & .venv/bin/Activate.ps1       # macOS / Linux
    }
    uv sync
}
Set-Alias -Name uvproj -Value Enter-UvProject
```

#### 8.8.6 多 profile 拆分(配置更整洁)

把 uv 相关配置单独放到 `~\Documents\PowerShell\uv.ps1`, 然后在主 profile 里 `. ./uv.ps1`:

```powershell
# $PROFILE
. "$PSScriptRoot/uv.ps1"
```

`uv.ps1` 内容:

```powershell
# uv 相关:env 变量 + PATH + 补全
$env:UV_INDEX_URL = "https://pypi.tuna.tsinghua.edu.cn/simple"
$env:UV_CACHE_DIR = if ($IsWindows) { "$env:LOCALAPPDATA\uv\cache" } else { "$HOME/.cache/uv" }
$uvBin = if ($IsWindows) { "$env:LOCALAPPDATA\uv" } else { "$HOME/.local/bin" }
if (Test-Path $uvBin) { $env:Path = "$uvBin;$env:Path" }
uv generate-shell-completion pwsh | Out-String | Invoke-Expression
```

好处:可以把 uv / git / docker 等拆成多个 `.ps1`,主 profile 只负责串联。

#### 8.8.7 跨机器同步 pwsh profile(可选)

把 `$PROFILE` 与 `uv.ps1` 等子文件放到 **Git 仓库**(例如 `~/dotfiles/powershell/`),然后用符号链接同步:

```powershell

New-Item -ItemType SymbolicLink `
    -Path "$HOME\Documents\PowerShell\Microsoft.PowerShell_profile.ps1" `
    -Target "$HOME\dotfiles\powershell\Microsoft.PowerShell_profile.ps1"

ln -sf ~/dotfiles/powershell/Microsoft.PowerShell_profile.ps1 \

```

#### 8.8.8 性能小贴士

- 不要在 `$PROFILE` 里跑耗时命令(如 `uv self update`),会拖慢启动。
- 把 **一次性** 的初始化放进 `if (-not $Global:ProfileLoaded) { ... }`,避免重复执行。
- 跨平台配置时, 用 `$IsWindows` / `$IsLinux` / `$IsMacOS` 做平台分支, 别用 `if ($PSVersionTable.PSVersion.Major -ge 7)` 反复判断。
- 想看 `$PROFILE` 启动耗时:`Measure-Command { . $PROFILE }`。
